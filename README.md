# Orbit-View
Software-based satellite tracking and weather-image visualization dashboard.

## Planned features
- Satellite orbit and pass prediction
- Azimuth and elevation visualization
- Virtual antenna animation
- Satellite recording retrieval
- NOAA APT weather-image decoding

- Frontend: 
- Backend: Python and FastAPI
- Satellite data: CelesTrak and SatNOGS
